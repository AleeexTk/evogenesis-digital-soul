# 🔺 EVO_PYRAMID 3D Interface

Полностью интерактивный 3D интерфейс для визуализации протокола Genesis с использованием Three.js.

## ✨ Возможности

### 🎮 3D Визуализация
- **Интерактивная 3D пирамида** с реалистичным освещением и эффектами свечения
- **Вращение мышкой** - зажмите левую кнопку и перетаскивайте для вращения
- **Масштабирование** - используйте колесико мыши для приближения/отдаления
- **Авто-вращение** - автоматическое вращение пирамиды (включается/выключается)

### 🎯 Интерактивность
- **Клик по граням** - нажмите на любую грань пирамиды для отображения деталей модуля
- **Информационная панель** - всплывающая панель с подробной информацией о каждом модуле
- **Кнопки выбора модулей** - быстрый доступ к любому модулю через боковую панель
- **Цветовая индикация** - каждый модуль имеет свой уникальный цвет

### 🎨 Визуальные эффекты
- **Particle System** - плавающие частицы вокруг пирамиды
- **Glow эффекты** - свечение для каждого модуля
- **Wireframe режим** - отображение каркаса пирамиды
- **Динамические метки** - текстовые метки для каждого модуля

### ⚙️ Настройки
- **Wireframe Mode** - включение/выключение каркасного отображения
- **Particles** - управление системой частиц
- **Glow Effects** - управление эффектами свечения
- **Labels** - показ/скрытие текстовых меток

## 🏗️ Структура модулей

### CORE (Белый) - Центральное ядро
- Центральная сфера в центре пирамиды
- Функции: инициализация, загрузка модулей, управление синхронизацией

### SOUL (Зеленый) - Архитектор
- Верхняя грань пирамиды
- Функции: управление игроком, поддержка памяти души

### TRAILBLAZER (Золотой) - Оптимизатор
- Правая грань пирамиды
- Функции: оптимизация данных, синхронизация систем

### PROVOCATEUR (Красный) - Страж
- Левая грань пирамиды
- Функции: провокация обсуждений, валидация структуры

### ANALYST (Фиолетовый) - Аналитик
- Задняя грань пирамиды
- Функции: анализ запросов, создание мостов

## 🚀 Использование

### Запуск
1. Откройте `index.html` в современном браузере (Chrome, Firefox, Edge)
2. Интерфейс автоматически загрузится и инициализирует 3D сцену

### Управление
- **Вращение**: Зажмите левую кнопку мыши и перетаскивайте
- **Масштабирование**: Прокручивайте колесико мыши
- **Выбор модуля**: Кликните на грань пирамиды или используйте кнопки в боковой панели
- **Сброс камеры**: Нажмите кнопку ⟲ в шапке
- **Авто-вращение**: Нажмите кнопку 🔄 для включения/выключения

### Интеграция с бэкендом
Интерфейс пытается загрузить данные из API эндпоинта:
```
/api/bridge/protocol
```

Если API недоступен, используются данные по умолчанию из `genesis_protocol.json`.

### Структура данных
Протокол использует следующую структуру JSON:
```json
{
  "genesis_meta": {
    "protocol_id": "EVO-GENESIS-V1",
    "timestamp": "2026-02-14T20:40:00Z",
    "version": "1.3.0",
    "state": "ACTIVE"
  },
  "modules": {
    "CORE": { ... },
    "SOUL": { ... },
    "TRAILBLAZER": { ... },
    "PROVOCATEUR": { ... },
    "PURPLE_TRIANGLE": { ... }
  }
}
```

## 🎨 Кастомизация

### Цвета модулей
В файле `style.css` измените CSS переменные:
```css
--color-core: #ffffff;
--color-soul: #00ff9d;
--color-trailblazer: #ffd700;
--color-provocateur: #ff4d4d;
--color-purple: #a020f0;
```

### Конфигурация модулей
В файле `app.js` измените объект `MODULE_CONFIG`:
```javascript
const MODULE_CONFIG = {
    'SOUL': {
        position: [0, 1.5, 0],
        color: 0x00ff9d,
        label: 'SOUL'
    },
    // ...
}
```

## 📦 Зависимости

- **Three.js r128** - 3D графика
- **Google Fonts** - Share Tech Mono, Orbitron

Все зависимости загружаются из CDN, установка не требуется.

## 🌐 Локализация

Интерфейс поддерживает два языка:
- 🇺🇦 Українська (UA) - по умолчанию
- 🇬🇧 English (EN)

Переключение через кнопки UA/EN в шапке интерфейса.

## 📱 Адаптивность

Интерфейс адаптируется под разные размеры экрана:
- Десктоп (> 1200px) - полная панель управления
- Планшет (900-1200px) - уменьшенная панель
- Мобильные (< 900px) - панель переносится вниз

## 🔧 Системные требования

- Современный браузер с поддержкой WebGL
- Минимум 2GB RAM
- Рекомендуется дискретная видеокарта для плавной работы эффектов

## 📝 Логирование

Все действия пользователя и системные события логируются в консоль в правой панели:
- `[SYSTEM]` - системные сообщения (серый)
- `[SUCCESS]` - успешные операции (зеленый)
- `[ERROR]` - ошибки (красный)
- `[WARN]` - предупреждения (желтый)
- `[INFO]` - информационные сообщения (фиолетовый)

## 🎯 Экспорт данных

Нажмите кнопку **📥 EXPORT DATA** для сохранения текущего протокола в JSON файл.
