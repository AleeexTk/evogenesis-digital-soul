🛡️ EvoP-Security: Deterministic Security Layer for LLM Agents
EvoP-Security is a lightweight, drop-in security module designed to govern the interactions between Large Language Models (LLMs), external tools, and the internet.
Unlike "LLM-based security" (which can be hallucinated or jailbroken), EvoP-Security uses deterministic policy engines to enforce strict rules on:
 * Visibility: Logging every execution event to NDJSON (SIEM-ready).
 * Control: Blocking, delaying, or modifying requests based on risk levels.
 * Network: A controlled HTTPClient acting as a secure gateway.

├── event_tap.py          # Central logging system (NDJSON exporter)
├── policy_engine.py      # Deterministic rule evaluator (YAML-based)
├── http_client.py        # Secure HTTP wrapper (Cache, Mock, Policy)
├── __init__.py

🚀 Installation
 * Dependencies:
   The core logic is pure Python. PyYAML is required for policy configuration. httpx is recommended for async HTTP requests.
   pip install pyyaml httpx

 * Setup:
   Copy the core/security folder into your project root. Ensure security_policies.yaml is in your working directory.
⚙️ Configuration (security_policies.yaml)
Define your rules in a simple YAML format. The engine supports deny, delay, and fallback actions based on context (User ID, Trust Level, Provider, Intent).
# 1. DENY: Block dangerous actions
deny:
  - condition:
      origin: tool
      intent: destructive
    reason: "Destructive tools are strictly prohibited."

  - condition:
      origin: http
      provider: "api.telegram.org"
    reason: "Messaging APIs are blocked for this agent."

# 2. DELAY: Throttle low-trust users or expensive operations
delay:
  - condition:
      origin: llm
      trust_level: {lt: 0.2} # Less than 20% trust
    reason: "Low trust session: artificial delay applied."
    delay_seconds: 1.5

# 3. FALLBACK: Downgrade providers or mock responses
fallback:
  - condition:
      origin: llm
      provider: "openai"
      trust_level: {lt: 0.5}
    reason: "Cost saving: forcing local model for low trust."
    modified_params:
      provider: "ollama" # Switches provider dynamically

🛠️ Usage
1. The Secure HTTP Client
Replace standard requests or aiohttp calls with HTTPClient. It handles caching, mocking, and policy enforcement automatically.
from core.security.event_tap import EventTap
from core.security.policy_engine import PolicyEngine
from core.security.http_client import HTTPClient

# Initialize
tap = EventTap(ndjson_path="logs/security.ndjson")
engine = PolicyEngine(config_path="security_policies.yaml")
http = HTTPClient(event_tap=tap, policy_engine=engine)

# Make a request (Context is mandatory for policy checks)
try:
    response = await http.get(
        "https://api.example.com/data",
        user_id="user_123",
        trust_level=0.8,
        intent="fetch_data"
    )
    print(response["json"])
except PermissionError as e:
    print(f"Request blocked: {e}")

2. Integrating with LLM Orchestrator
Inject the security context into your generation calls. The PolicyEngine will intercept the call before it hits the API.
# Inside your LLM Orchestrator
async def generate(self, prompt, **kwargs):
    # 1. Evaluate Policy
    decision = self.policy_engine.evaluate({
        "origin": "llm",
        "intent": "chat",
        "trust_level": kwargs.get("trust_level", 1.0)
    })

    # 2. Enforce Decision
    if decision.action == "deny":
        raise SecurityViolation(decision.reason)
    
    # 3. Log & Execute
    return await self.event_tap.aintercept(
        fn=self._call_llm_api,
        origin="llm",
        provider="openai",
        intent="chat",
        # ... args
    )

3. Tool Execution Gate
Ensure tools are executed through a wrapper that checks permissions.
# In your ToolRegistry
async def execute_tool(name, args, security_ctx):
    spec = self.get_tool(name)
    
    # Check policy before running
    decision = policy_engine.evaluate({
        "origin": "tool",
        "intent": spec.risk_level, # e.g., "read_only", "destructive"
        "user_id": security_ctx["user_id"]
    })

    if decision.action == "deny":
        return "Tool execution denied by policy."

    return await event_tap.aintercept(spec.fn, **args)

🔒 Security Principles
 * Deterministic over Probabilistic: We do not ask an LLM if an action is safe. We check a hard-coded policy file.
 * Fail-Safe defaults: If the policy engine fails, the default action should be to log and deny (configurable).
 * Complete Observability: If it's not logged, it didn't happen. EventTap ensures visibility into all side effects.
🔜 Roadmap
 * Wallet Manager: Token budgeting and credit systems per session.
 * Semantic Caching: Deduplicating similar LLM requests to save costs.
 * PII Redaction: Automatic scrubbing of sensitive data in logs.

```python
"""
core/security/event_tap.py

Єдина точка логування всіх зовнішніх викликів.
Пише NDJSON + (опційно) передає в SIEMExporter.
"""

from __future__ import annotations

import json
import time
import uuid
from dataclasses import dataclass, asdict
from datetime import datetime, timezone
from typing import Any, Callable, Dict, List, Optional


def _utc_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


@dataclass
class ExecutionEvent:
    event_id: str
    origin: str            # "llm" | "tool" | "http"
    intent: str
    provider: str
    estimated_cost: float
    latency: float
    status: str            # "allowed" | "denied" | "delayed" | "error" | "fallback"
    policy_rules: List[str]
    timestamp: str

    # Контекст (для аналітики)
    user_id: Optional[str] = None
    session_id: Optional[str] = None
    trust_level: Optional[float] = None
    policy_mode: Optional[str] = None
    meta: Optional[Dict[str, Any]] = None


class EventTap:
    def __init__(
        self,
        ndjson_path: str = "security_event_stream.ndjson",
        exporter: Optional[Any] = None,
    ) -> None:
        self.ndjson_path = ndjson_path
        self.exporter = exporter

    def record(self, event: ExecutionEvent) -> None:
        payload = asdict(event)

        # 1) Exporter (SIEM, ThreatIntel)
        if self.exporter:
            try:
                self.exporter.export_event(
                    event_type="execution",
                    severity="info" if event.status in ("allowed", "delayed") else "warning",
                    details=payload,
                    priority="medium",
                )
            except Exception:
                pass  # не ламаємо виконання

        # 2) NDJSON
        with open(self.ndjson_path, "a", encoding="utf-8") as f:
            f.write(json.dumps(payload, ensure_ascii=False, default=str) + "\n")

    async def aintercept(
        self,
        fn: Callable[..., Any],
        *,
        origin: str,
        provider: str,
        intent: str,
        estimated_cost: float = 0.0,
        policy_rules: Optional[List[str]] = None,
        context: Optional[Dict[str, Any]] = None,
        status_on_success: str = "allowed",
        denied_reason: Optional[str] = None,
        **call_kwargs: Any,
    ) -> Any:
        start = time.time()
        event_id = f"evt_{uuid.uuid4().hex[:10]}"
        policy_rules = policy_rules or []
        ctx = context or {}

        try:
            result = await fn(**call_kwargs)
            latency = time.time() - start
            self.record(
                ExecutionEvent(
                    event_id=event_id,
                    origin=origin,
                    intent=intent,
                    provider=provider,
                    estimated_cost=float(estimated_cost),
                    latency=latency,
                    status=status_on_success,
                    policy_rules=policy_rules,
                    timestamp=_utc_iso(),
                    user_id=ctx.get("user_id"),
                    session_id=ctx.get("session_id"),
                    trust_level=ctx.get("trust_level"),
                    policy_mode=ctx.get("policy_mode"),
                    meta=ctx.get("meta"),
                )
            )
            return result
        except Exception as e:
            latency = time.time() - start
            meta = dict(ctx.get("meta") or {})
            meta["error"] = repr(e)
            if denied_reason:
                meta["denied_reason"] = denied_reason
            self.record(
                ExecutionEvent(
                    event_id=event_id,
                    origin=origin,
                    intent=intent,
                    provider=provider,
                    estimated_cost=float(estimated_cost),
                    latency=latency,
                    status="error",
                    policy_rules=policy_rules,
                    timestamp=_utc_iso(),
                    user_id=ctx.get("user_id"),
                    session_id=ctx.get("session_id"),
                    trust_level=ctx.get("trust_level"),
                    policy_mode=ctx.get("policy_mode"),
                    meta=meta,
                )
            )
            raise
```

```python
"""
core/security/policy_engine.py

Детермінований рушій політик: deny / fallback / delay / allow.
Конфігурація – YAML з умовами та операторами.
"""

from __future__ import annotations

from dataclasses import dataclass
from enum import Enum
from typing import Any, Dict, List, Optional


class DecisionAction(str, Enum):
    ALLOW = "allow"
    DENY = "deny"
    DELAY = "delay"
    FALLBACK = "fallback"


@dataclass(frozen=True)
class PolicyDecision:
    action: DecisionAction
    reason: str
    policy_rules: List[str]
    modified_params: Optional[Dict[str, Any]] = None
    delay_seconds: Optional[float] = None


def _to_float(x: Any) -> Optional[float]:
    try:
        return float(x)
    except Exception:
        return None


def _match_condition(condition: Dict[str, Any], ctx: Dict[str, Any]) -> bool:
    """
    Підтримує оператори: lt, lte, gt, gte, ne, in, not_in.
    Приклад:
      condition:
        trust_level: {lt: 0.4}
        provider: {in: ["openai", "anthropic"]}
    """
    for key, expected in condition.items():
        actual = ctx.get(key)

        # просте порівняння
        if not isinstance(expected, dict):
            if actual != expected:
                return False
            continue

        # оператори
        for op, val in expected.items():
            if op in ("lt", "lte", "gt", "gte"):
                a = _to_float(actual)
                b = _to_float(val)
                if a is None or b is None:
                    return False
                if op == "lt" and not (a < b):
                    return False
                if op == "lte" and not (a <= b):
                    return False
                if op == "gt" and not (a > b):
                    return False
                if op == "gte" and not (a >= b):
                    return False
            elif op == "ne":
                if actual == val:
                    return False
            elif op == "in":
                if actual not in list(val):
                    return False
            elif op == "not_in":
                if actual in list(val):
                    return False
            else:
                return False
    return True


class PolicyEngine:
    def __init__(self, rules: Optional[Dict[str, Any]] = None, config_path: str = "security_policies.yaml"):
        if rules is not None:
            self.rules = rules
            return

        try:
            import yaml
        except ImportError:
            raise RuntimeError(
                "PyYAML is required for PolicyEngine. Install: pip install pyyaml"
            ) from None

        with open(config_path, "r", encoding="utf-8") as f:
            self.rules = yaml.safe_load(f) or {}

    def evaluate(self, ctx: Dict[str, Any]) -> PolicyDecision:
        # 1) deny
        for i, rule in enumerate(self.rules.get("deny", [])):
            if _match_condition(rule.get("condition", {}), ctx):
                return PolicyDecision(
                    action=DecisionAction.DENY,
                    reason=rule.get("reason", "blocked by policy"),
                    policy_rules=[f"deny[{i}]"],
                )

        # 2) delay
        for i, rule in enumerate(self.rules.get("delay", [])):
            if _match_condition(rule.get("condition", {}), ctx):
                return PolicyDecision(
                    action=DecisionAction.DELAY,
                    reason=rule.get("reason", "delayed by policy"),
                    policy_rules=[f"delay[{i}]"],
                    delay_seconds=float(rule.get("delay_seconds", 0.5)),
                )

        # 3) fallback
        for i, rule in enumerate(self.rules.get("fallback", [])):
            if _match_condition(rule.get("condition", {}), ctx):
                modified = rule.get("modified_params") or {}
                # backward compatibility
                if "provider" not in modified and rule.get("fallback_provider"):
                    modified["provider"] = rule["fallback_provider"]
                return PolicyDecision(
                    action=DecisionAction.FALLBACK,
                    reason=rule.get("reason", "fallback by policy"),
                    policy_rules=[f"fallback[{i}]"],
                    modified_params=modified,
                )

        # default allow
        return PolicyDecision(
            action=DecisionAction.ALLOW,
            reason="default allow",
            policy_rules=["default"],
        )
```

```python
"""
core/security/http_client.py

Контрольований HTTP-клієнт: логування, політика, кеш, мок.
Третій origin ("http") в системі EvoP-Security.
"""

from __future__ import annotations

import asyncio
import json
import time
from dataclasses import dataclass
from datetime import datetime
from typing import Any, Dict, Optional, Tuple
from urllib.parse import urlparse

try:
    import httpx
except ImportError:
    httpx = None

try:
    import requests
except ImportError:
    requests = None

from core.security.event_tap import EventTap, ExecutionEvent
from core.security.policy_engine import PolicyEngine, DecisionAction


class HTTPPolicyError(PermissionError):
    """Викликається, коли HTTP-запит відхилено політикою."""


@dataclass
class HTTPCacheEntry:
    status_code: int
    headers: Dict[str, str]
    body: bytes
    stored_at: float
    ttl_seconds: int

    def alive(self) -> bool:
        return (time.time() - self.stored_at) <= self.ttl_seconds


def _now_iso() -> str:
    return datetime.utcnow().isoformat() + "Z"


def _host_of(url: str) -> str:
    try:
        return (urlparse(url).hostname or "").lower()
    except Exception:
        return ""


def _default_headers(headers: Optional[Dict[str, str]]) -> Dict[str, str]:
    h = dict(headers or {})
    if "User-Agent" not in {k.title(): v for k, v in h.items()}:
        h.setdefault("User-Agent", "EvoP-Security-HTTPClient/0.1")
    return h


class HTTPClient:
    def __init__(
        self,
        event_tap: EventTap,
        policy_engine: PolicyEngine,
        *,
        cache_enabled: bool = True,
        cache_ttl_seconds: int = 120,
        mock_responses: Optional[Dict[Tuple[str, str], Dict[str, Any]]] = None,
        timeout_seconds: float = 15.0,
    ):
        self.event_tap = event_tap
        self.policy_engine = policy_engine
        self.cache_enabled = cache_enabled
        self.cache_ttl_seconds = cache_ttl_seconds
        self.timeout_seconds = timeout_seconds
        self._cache: Dict[Tuple[str, str, str], HTTPCacheEntry] = {}
        self.mock_responses = mock_responses or {}

    async def request(
        self,
        method: str,
        url: str,
        *,
        params: Optional[Dict[str, Any]] = None,
        headers: Optional[Dict[str, str]] = None,
        json_body: Optional[Any] = None,
        data: Optional[Any] = None,
        timeout_seconds: Optional[float] = None,
        # --- контекст безпеки ---
        user_id: Optional[str] = None,
        session_id: Optional[str] = None,
        trust_level: float = 1.0,
        intent: str = "http_request",
        policy_mode: Optional[str] = None,
    ) -> Dict[str, Any]:
        """
        Повертає нормалізований dict-відповідь:
        {
            "status_code": int,
            "headers": dict,
            "text": str,
            "json": dict | None,
            "url": str,
            "from_cache": bool,
            "from_mock": bool
        }
        """
        method_u = (method or "GET").upper()
        host = _host_of(url)
        hdrs = _default_headers(headers)
        t0 = time.time()
        event_id = f"evt_http_{int(t0 * 1000)}"

        # --- Policy evaluation ---
        decision = self.policy_engine.evaluate({
            "origin": "http",
            "provider": host,
            "method": method_u,
            "url": url,
            "intent": intent,
            "user_id": user_id,
            "session_id": session_id,
            "trust_level": trust_level,
            "policy_mode": policy_mode,
        })

        # Примусова затримка
        if decision.action == DecisionAction.DELAY and decision.delay_seconds:
            await asyncio.sleep(decision.delay_seconds)

        # Відмова
        if decision.action == DecisionAction.DENY:
            self._record_event(event_id, intent, host, 0.0, "denied", [decision.reason])
            raise HTTPPolicyError(decision.reason)

        # Fallback (кеш / мок)
        if decision.action == DecisionAction.FALLBACK:
            resp = self._fallback_response(method_u, url)
            self._record_event(event_id, intent, host, time.time() - t0, "fallback", [decision.reason])
            return resp

        # --- Кеш для GET ---
        if self.cache_enabled and method_u == "GET":
            cache_key = (method_u, url, json.dumps(params or {}, sort_keys=True))
            cached = self._cache.get(cache_key)
            if cached and cached.alive():
                self._record_event(event_id, intent, host, time.time() - t0, "allowed", ["cache_hit"])
                return self._normalize_cached(url, cached)

        # --- Реальний запит ---
        try:
            resp = await self._do_request(
                method_u,
                url,
                params=params,
                headers=hdrs,
                json_body=json_body,
                data=data,
                timeout_seconds=timeout_seconds or self.timeout_seconds,
            )
            latency = time.time() - t0
            self._record_event(event_id, intent, host, latency, "allowed", [decision.reason])

            # Збереження в кеш
            if self.cache_enabled and method_u == "GET":
                cache_key = (method_u, url, json.dumps(params or {}, sort_keys=True))
                self._cache[cache_key] = HTTPCacheEntry(
                    status_code=resp["status_code"],
                    headers=resp.get("headers", {}),
                    body=resp.get("_body_bytes", b""),
                    stored_at=time.time(),
                    ttl_seconds=self.cache_ttl_seconds,
                )
            resp.pop("_body_bytes", None)
            return resp
        except Exception as e:
            latency = time.time() - t0
            self._record_event(event_id, intent, host, latency, "error", [f"exception:{type(e).__name__}"])
            raise

    async def get(self, url: str, **kwargs) -> Dict[str, Any]:
        return await self.request("GET", url, **kwargs)

    async def post(self, url: str, **kwargs) -> Dict[str, Any]:
        return await self.request("POST", url, **kwargs)

    # ---------- private ----------
    def _record_event(self, event_id: str, intent: str, provider: str,
                      latency: float, status: str, policy_rules: list[str]) -> None:
        self.event_tap.record(
            ExecutionEvent(
                event_id=event_id,
                origin="http",
                intent=intent,
                provider=provider or "unknown",
                estimated_cost=0.0,
                latency=latency,
                status=status,
                policy_rules=policy_rules,
                timestamp=_now_iso(),
            )
        )

    def _fallback_response(self, method: str, url: str) -> Dict[str, Any]:
        # 1) точний мок
        mock = self.mock_responses.get((method, url))
        if mock:
            return self._normalize_mock(url, mock)

        # 2) кеш (тільки GET)
        if self.cache_enabled and method == "GET":
            cache_key = (method, url, json.dumps({}, sort_keys=True))
            cached = self._cache.get(cache_key)
            if cached and cached.alive():
                return self._normalize_cached(url, cached)

        # 3) безпечний fallback
        return {
            "status_code": 599,
            "headers": {},
            "text": "",
            "json": None,
            "url": url,
            "from_cache": False,
            "from_mock": False,
        }

    def _normalize_cached(self, url: str, cached: HTTPCacheEntry) -> Dict[str, Any]:
        body = cached.body or b""
        text = body.decode("utf-8", errors="replace")
        parsed = None
        try:
            parsed = json.loads(text)
        except Exception:
            pass
        return {
            "status_code": cached.status_code,
            "headers": cached.headers,
            "text": text,
            "json": parsed,
            "url": url,
            "from_cache": True,
            "from_mock": False,
        }

    def _normalize_mock(self, url: str, mock: Dict[str, Any]) -> Dict[str, Any]:
        status = int(mock.get("status_code", 200))
        headers = dict(mock.get("headers", {}))
        if "json" in mock:
            text = json.dumps(mock["json"])
            parsed = mock["json"]
            body = text.encode("utf-8")
        elif "text" in mock:
            text = str(mock["text"])
            parsed = None
            body = text.encode("utf-8")
        else:
            body = mock.get("body", b"")
            text = body.decode("utf-8", errors="replace")
            try:
                parsed = json.loads(text)
            except Exception:
                parsed = None
        return {
            "status_code": status,
            "headers": headers,
            "text": text,
            "json": parsed,
            "url": url,
            "from_cache": False,
            "from_mock": True,
        }

    async def _do_request(
        self,
        method: str,
        url: str,
        *,
        params: Optional[Dict],
        headers: Dict[str, str],
        json_body: Optional[Any],
        data: Optional[Any],
        timeout_seconds: float,
    ) -> Dict[str, Any]:
        # 1) httpx (async)
        if httpx is not None:
            async with httpx.AsyncClient(timeout=timeout_seconds, follow_redirects=True) as client:
                r = await client.request(
                    method, url, params=params, headers=headers,
                    json=json_body, data=data
                )
                body = r.content or b""
                text = body.decode("utf-8", errors="replace")
                parsed = None
                try:
                    parsed = r.json()
                except Exception:
                    pass
                return {
                    "status_code": r.status_code,
                    "headers": dict(r.headers),
                    "text": text,
                    "json": parsed,
                    "url": str(r.url),
                    "_body_bytes": body,
                }

        # 2) requests (sync -> thread)
        if requests is not None:
            def _sync_req():
                r = requests.request(
                    method, url, params=params, headers=headers,
                    json=json_body, data=data, timeout=timeout_seconds
                )
                body = r.content or b""
                text = body.decode("utf-8", errors="replace")
                parsed = None
                try:
                    parsed = r.json()
                except Exception:
                    pass
                return {
                    "status_code": r.status_code,
                    "headers": dict(r.headers),
                    "text": text,
                    "json": parsed,
                    "url": r.url,
                    "_body_bytes": body,
                }
            return await asyncio.to_thread(_sync_req)

        # 3) urllib (sync -> thread) – останній шанс
        import urllib.request
        import urllib.parse

        def _sync_urllib():
            q = urllib.parse.urlencode(params or {})
            full = url if not q else f"{url}?{q}"
            payload = None
            if json_body is not None:
                payload = json.dumps(json_body).encode("utf-8")
                headers["Content-Type"] = "application/json"
            elif data is not None:
                if isinstance(data, (bytes, bytearray)):
                    payload = bytes(data)
                else:
                    payload = str(data).encode("utf-8")
            req = urllib.request.Request(full, data=payload, method=method, headers=headers)
            with urllib.request.urlopen(req, timeout=timeout_seconds) as resp:
                body = resp.read() or b""
                text = body.decode("utf-8", errors="replace")
                parsed = None
                try:
                    parsed = json.loads(text)
                except Exception:
                    pass
                return {
                    "status_code": getattr(resp, "status", 200),
                    "headers": dict(resp.headers.items()),
                    "text": text,
                    "json": parsed,
                    "url": full,
                    "_body_bytes": body,
                }

        return await asyncio.to_thread(_sync_urllib)
```

```python
async def execute(
    self,
    name: str,
    args: Dict[str, Any],
    *,
    event_tap: EventTap,
    policy_engine: PolicyEngine,
    security_ctx: Optional[Dict[str, Any]] = None,
    policy_mode: str = "none",
) -> Any:
    """
    Єдина точка виконання інструментів:
      - PolicyGate (deterministic)
      - EventTap (visibility)
    """
    spec = self.get(name)
    if not spec:
        raise ValueError(f"Tool not found: {name}")

    ctx = dict(security_ctx or {})
    ctx.setdefault("intent", spec.risk)
    ctx.setdefault("policy_mode", policy_mode)

    decision = policy_engine.evaluate({
        "origin": "tool",
        "provider": spec.name,
        "intent": spec.risk,
        "user_id": ctx.get("user_id"),
        "session_id": ctx.get("session_id"),
        "estimated_cost": 0.0,
        "trust_level": ctx.get("trust_level", 1.0),
        "policy_mode": ctx.get("policy_mode"),
    })

    if decision.action == DecisionAction.DENY:
        await event_tap.aintercept(
            fn=self._noop_async,
            origin="tool",
            provider=spec.name,
            intent=spec.risk,
            policy_rules=decision.policy_rules,
            context=ctx,
            status_on_success="denied",
            denied_reason=decision.reason,
        )
        raise PermissionError(decision.reason)

    if decision.action == DecisionAction.DELAY and decision.delay_seconds:
        await asyncio.sleep(decision.delay_seconds)

    async def _call():
        fn = spec.fn
        if inspect.iscoroutinefunction(fn):
            return await fn(**args)
        return fn(**args)

    status = "allowed" if decision.action in (DecisionAction.ALLOW, DecisionAction.FALLBACK) else "delayed"
    return await event_tap.aintercept(
        fn=_call,
        origin="tool",
        provider=spec.name,
        intent=spec.risk,
        policy_rules=decision.policy_rules,
        context=ctx,
        status_on_success=status,
    )

async def _noop_async(self, **kwargs):
    return None
```
