🎮 Как Использовать

  • Вращение: Зажмите левую кнопку мыши и перетаскивайте для вращения пирамиды
  • Масштабирование: Прокручивайте колесико мыши для приближения/отдаления
  • Выбор модуля: Кликните на грань пирамиды для просмотра деталей
  • Авто-вращение: Нажмите кнопку 🔄 для включения/выключения автоматического вращения
  • Сброс камеры: Кнопка ⟲ вернет камеру в исходное положение
  • Настройки: Используйте правую панель для управления визуальными эффектами
  • Экспорт: Кнопка 📥 EXPORT DATA сохранит протокол в JSON файл
